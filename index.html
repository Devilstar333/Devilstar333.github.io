Advanced settings (context, reserves)

The KV cache takes extra VRAM/RAM that grows with the context — in practice it is the #1 cause of OOM after the weights.

Preset defaults: 32 GB RAM · 12 GB VRAM · 24B · Q4_K_M (the typical setup for LM Studio / Roo Code users).

How these numbers are estimated

  • Weights = parameters (B) × effective bits ÷ 8 — Q4_K_M ≈ 4.5 bits/weight, Q6_K ≈ 6.5, Q8_0 ≈ 8.5, FP16 = 16.
  • Overhead = 20% of the weights + 0.6 GB of compute/runtime buffers (CUDA / Metal / ROCm).
  • KV cache ≈ 0.007 GB × billions of parameters × (context ÷ 1024), calibrated on GQA models.
  • Usable VRAM = VRAM − display reserve; usable RAM = RAM − OS and app reserve.
  • Speed ≈ effective memory bandwidth (GPU ~600 GB/s, DDR5 ~80 GB/s) ÷ total memory, capped at 150 tok/s.

These are approximations: MoE architectures, quantized KV cache, layer-split multi-GPU and prompt processing are not modeled. Use them as an order of magnitude to decide what to download, not as a guarantee. None of the data you type leaves your browser — the whole calculation runs client-side.
